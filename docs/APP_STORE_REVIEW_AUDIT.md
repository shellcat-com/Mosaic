## Submission blockers — complete in this order

1. **Authenticate Apple tooling.** Sign in to the prepared App Store Connect browser tab and configure `asc` credentials so the app, version, build, and review-detail IDs can be resolved.
2. **Finish Supabase dashboard hardening.** Under Authentication → Sign In / Providers, disable Anonymous Sign-Ins. Mosaic's Apple-only RPC boundary and profile privileges already reject anonymous users, but disabling the unused provider prevents throwaway Auth rows and clears the corresponding advisor warning.
3. **Finish Apple commerce setup.** Accept the Paid Apps agreement and complete tax/banking. Create `organizer_monthly`, `organizer_annual`, and `mosaic_event_pass_v2`; add pricing, localizations, review screenshots, and the subscription group; attach them to version 1.0. Create RevenueCat's real App Store configuration using Apple's in-app-purchase `.p8` key, Key ID, and Issuer ID, then add its public SDK key to the ignored `Config/Local.xcconfig`.
4. **Run genuine purchase tests.** With sandbox accounts, record evidence for monthly and annual purchase, Event Pass purchase/consumption semantics, restore, cancellation, pending/Ask to Buy, expiration/grace behavior, relaunch, and server entitlement reconciliation.
5. **Publish privacy answers.** Match App Store Connect to the target manifest: Name, Email Address, User ID, Photos/Videos, Other User Content, and Purchase History; no tracking. Generate Organizer's Privacy Report and reconcile SDK declarations before publishing.
6. **Complete compliance forms.** Finish export compliance for AES-GCM/Swift Crypto, the current age-rating questionnaire, content-rights answers, and DSA/trader status where applicable.
7. **Finish reviewer materials.** Record the current app using `docs/APP_REVIEW_VIDEO_SCRIPT.md`, upload the final MP4 as a review attachment, and fill the reviewer contact name/phone. The hosted invitation is `REVIEW26`.
8. **Produce the distribution candidate.** Install an Apple Distribution certificate/profile, query the next unused build number, run physical-device camera/purchase checks, export/upload the Release archive, and select the processed build.
9. **Validate App Store Connect.** Run strict metadata, IAP, and subscription validation, resolve every ERROR/WARNING, recheck every public URL, and stop before Submit for Review.

Suggested validation command after credentials and the app ID are available:

```sh
asc validate --app APP_ID --version 1.0 --platform IOS --strict --output table
```
