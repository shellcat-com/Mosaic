# TestFlight Beta App Review notes

> Archived billing-disabled Reverie build notes. The Shipaton Next Gen entry is
> evaluated from its public repository and demonstration video.

Mosaic is a consent-first collaborative kindness app submitted for Reverie Hacks 2026.

No credentials are required. On first launch, choose **Explore Demo**. The app creates an anonymous hosted Supabase user and opens a shared synthetic showcase. Open **Organizer Sandbox** from the demo home to review creation, moderation, tile placement, and reveal controls without Sign in with Apple.

The other first-launch actions are also functional:

- **Join a Mosaic** accepts the judging invitation code shown on the public invitation page.
- **Create a Mosaic** uses native Sign in with Apple for a recoverable organizer account. Cancelling safely returns to the entry screen and does not block the complete demo.

Billing, purchases, paywalls, and remote push delivery are disabled in this build. All displayed people, organizations, contributions, and media are synthetic. If the network is temporarily unavailable, the app clearly labels and opens a bundled read-only showcase; cloud writes are never represented as successful while offline.
